## 项目概览

NovelAgent 是一个面向长篇小说创作的智能体项目。用户输入题材、标签与核心想法后，系统建立创作方案，并逐章执行规划、写作、审核、修订和记忆更新。

[项目仓库](https://github.com/Tongtron/NovelAgent) · [我的 V2 提交与改动](https://github.com/Tongtron/NovelAgent/pull/1)

**当前展示版本：**V2 开发分支。下述扩展对应我以 `1011-wyl` 提交的 PR #1；截至 2026 年 9 月 5 日，该 PR 为草稿，尚未合并。本文展示开发实践，不代表已正式发布。

## 我的开发贡献

### 章节规划与写作流程

在 V2 提交中增加情绪优先的细化章节规划，包括目标情绪、读者回报、主角选择、多线推进、人物关系变化和字数预算。结合题材提示卡校准正文写法，并在初稿后加入语言润色与一致性审校步骤。

### 写作技能集成

集成固定版本的 Story Skills 与 oh-story 写作规则，分别用于跨章节一致性检查、情绪细纲、题材提示和语言润色。保留第三方来源与许可证，由 Python 宿主加载相关内容。

### 前端与接口

补充创作方案中的「读者契约」和「核心期待」展示、编辑字段，以及写作技能配置与运行状态。同步更新接口说明和中文使用手册，让创作流程与系统状态更容易理解。

## 系统设计

项目技术包括 Python、Pydantic、SQLite，以及 HTML、CSS、JavaScript 前端。在线模式接入 DeepSeek，离线模式用于本地流程验证。

1. 用户创建并确认创作方案。
2. 系统生成章节细纲，判断是否需要调研，再完成正文初稿。
3. 语言润色与一致性检查后，必要时进入修订循环。
4. 审核通过的正文、人物状态与时间线通过同一事务提交。
5. 控制台展示章节与运行事件，支持暂停、继续和阅读已有内容。

SQLite 是故事数据的权威存储。草稿与正式正文隔离，失败的工作流不会直接改写正式人物记忆，减少长篇生成中的状态不一致。

## 验证与边界

PR 中记录了 40 个单元测试通过、Python 编译检查通过，以及前端 JavaScript 语法检查通过。这是该次提交记录的验证结果。

当前项目的真实小说平台发布尚未实现，发布模块使用模拟状态。作品集仅展示项目介绍与源码入口，不在此页面运行小说生成服务。
